# 贡献与安全台架说明

## 贡献许可

本项目统一采用 Apache-2.0。提交贡献即表示同意按 Apache-2.0 提供，不移除上游版权、来源或修改通知。完整文本见根 `LICENSE`，归属和修改说明见 `NOTICE`。

## 开发流程

```bash
npm ci --ignore-scripts --no-audit --no-fund
npm run check
npm test
npm run build
```

测试不得默认访问真实 USB。协议和后端测试应优先使用 `test/` 中的内存模拟器；需要增加硬件测试时，应显式命名、说明设备和连接条件，并避免在无人值守环境发送 CAN 帧。

## 最小安全台架

1. 先确认设备的 VID/PID、接口、alternate setting、Bulk 端点和固件版本与文档一致。
2. 使用隔离总线、正确终端电阻和已知正常的 CAN 收发器；不要把第一次测试接到生产总线。
3. 先只做打开、描述符发现、初始化和停止；确认波特率后再发一帧低风险测试数据。
4. 逐步验证标准帧、扩展帧、RTR、双通道、拔插、关闭和重连。
5. 记录设备回显、总线分析仪观察结果和 RX/TX 队列行为；`flush` 成功不等于 CAN ACK。
6. 再做高负载、后台标签页、系统休眠和长时间轮询测试，并把可能丢帧作为预期风险评估。

## 浏览器环境

WebUSB 需要安全上下文和浏览器权限。Windows 可能需要对应接口由 WinUSB 暴露；Linux 可能需要 USB 设备访问权限。项目不会自动替换驱动、脱离内核驱动或修改系统权限。
